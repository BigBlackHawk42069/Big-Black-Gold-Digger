# Big Black Gold Digger

**Never miss a Golden Resource again.**

A [BepInEx](https://github.com/BepInEx/BepInEx) mod for **Bloobs Adventure Idle** that automatically collects the golden bonus the moment it appears. No more mousing over glowing trees to get your double materials.

Works with:

- 🌳 **Woodcutting**: golden trees
- ⛏️ **Mining**: golden ores
- 🌿 **Foraging**: golden bushes
- 💰 **Thieving**: golden chests
- 🎣 **Fishing**: golden fishing spots

You get the same reward as hovering over it yourself. It just happens automatically.

## Installation

1. **Install BepInEx 5** (skip this if you already have it):
   - Download `BepInEx_win_x64_5.4.23.x.zip` from the [BepInEx releases page](https://github.com/BepInEx/BepInEx/releases).
   - Extract it into your game folder, next to `Bloobs Adventure Idle.exe`.
   - Launch the game once, then close it.
2. **Install the mod:**
   - Download `BigBlackGoldDigger.zip` from [Releases](../../releases).
   - Extract it into your game folder. You should end up with:
     `BepInEx\plugins\BigBlackGoldDigger\BigBlackGoldDigger.dll`
3. **Play!**

> **Where's my game folder?** In Steam, right-click Bloobs Adventure Idle → **Manage** → **Browse local files**.

## Settings

After the first launch, open `BepInEx\config\BigBlackGoldDigger.cfg` to turn each resource type on or off, or hide the log messages. Edit it while the game is closed.

## Uninstall

Delete the `BepInEx\plugins\BigBlackGoldDigger` folder.
